# richdiff

文書の変更内容を、ブラウザ上で見た目のまま比較して提示するスキルである。
差分エンジンには live-web-diff-tool を用いる（本プラグインに同梱されたビルドを使用する）。

用途は 2 つある。ひとつは、md や html の記法に埋もれずに変更箇所を読むこと。
もうひとつは、**修正を重ねた未コミットのファイルについて、積み上がった変更を
文書全体として俯瞰すること**である。会話の中では変更が編集箇所の断片としてしか
提示されないため、全体像を確かめる手段として用いる。

**利用者が明示的に求めた場合にのみ使用する。**「diff を見せて」「差分を確認したい」
「適用する前に見せて」等の依頼を受けた場合に限る。自発的にブラウザを開いてはならない。
編集のたびに実行することも避ける。

## 呼び出し方は 2 通り

### 1. 未適用の変更を提示する場合

新しい内容を一時ファイルに書き出したうえで、`--proposed <対象パス>=<一時ファイル>` を指定する。

```
${CLAUDE_SKILL_DIR}/bin/richdiff.mjs --proposed docs/spec.md=/tmp/spec.new.md
```

- **本コマンドは対象ファイルを変更しない。** 読み取りのみを行う。
- 実行後は、ブラウザで表示した旨を伝えたうえで、**適用の可否を会話で確認する。**
- 承諾を得てから、通常どおり Edit / Write 等の編集ツールで書き込む。
- 一時ファイルの削除は、本スキルを使用する側の責務とする。

複数のファイルをまとめて提示する場合は、`--proposed` を繰り返し指定する。

```
${CLAUDE_SKILL_DIR}/bin/richdiff.mjs \
  --proposed docs/spec.md=/tmp/spec.new.md \
  --proposed README.md=/tmp/readme.new.md
```

### 2. 適用済みの変更を提示する場合

`--git` を指定し、HEAD と作業ツリーの差分を提示する。

```
${CLAUDE_SKILL_DIR}/bin/richdiff.mjs --git path/to/file1.md path/to/file2.html
```

パスを省略した場合は、変更のあった全ファイルを対象とする。

- 作業開始前から未コミットの変更が存在した場合、それらも併せて表示される
  （HEAD との比較である以上、変更の時期を区別できない）。richdiff はその可能性を
  標準エラーに出力するため、**利用者にも同様に伝える。**
- 任意のリビジョンと比較する場合は `--git --rev <ref> ...` を使用する。

## 補足

- **対象パスはリポジトリからの相対パスで指定する。** ファイル切り替えの表示に
  そのまま用いられるため、絶対パスを渡すと画面上の表示が冗長になる。
- md / html 以外の拡張子は自動的にテキスト表示となる（`--view` による明示指定も可能）。
  コードの差分は git で参照できるため、本スキルの主たる対象ではない。
- 本コマンドはブラウザを開いた時点で終了する。サーバは独立したプロセスで動作するため、
  承認待ちのために応答を保留することはない。
- パスは常に `${CLAUDE_SKILL_DIR}/bin/richdiff.mjs` の形式で参照する
  （インストール先およびプラグインのバージョンに依存せず解決できる）。
- `--pair <変更前> <変更後>` や `--manifest <json>` 等、その他の指定方法については
  `${CLAUDE_SKILL_DIR}/bin/richdiff.mjs --help` を参照すること。
